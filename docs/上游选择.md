# 上游选择

## 采用
- 核心：<https://github.com/HERO-Lab-POSTECH/stonefish>，与集成包匹配的1.3版本。
- ROS 2集成、模型和控制：<https://github.com/HERO-Lab-POSTECH/stonefish_sim>。
- 原始核心作者：<https://github.com/patrykcieslak/stonefish>，Patryk Cieślak。

选择原因：明确支持 Ubuntu22.04/ROS2 Humble，已有BlueROV2模型、渲染、水动力、传感器与推力分配，适合在现有环境修改并实际验证。将锁定具体commit，不跟随分支更新。

## 比较
原作者 stonefish_ros2 提供标准接口，但BlueROV2模型/控制需要额外组装；HERO仓库已将这些包整合。DAVE现有ROS2路线主要面向Ubuntu24.04/Jazzy/Gazebo Harmonic，当前第一版采用与主机匹配的Stonefish。
